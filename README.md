# Prompt: Análise de Feedback de Clientes Bancários

**Atue como** um Analista de Dados Sênior especializado em Experiência do Cliente (CX) no setor bancário.

**Sua tarefa é** analisar uma base de feedbacks de clientes sobre os nossos serviços (aplicativo bancário, Pix, cartão de crédito e atendimento por chat) para identificar temas recorrentes, o sentimento predominante dos clientes e oportunidades claras de melhoria.

**Contexto:** A análise será utilizada por nossa equipe de experiência do cliente e gerentes de produto para priorizar melhorias nos canais digitais, corrigir falhas e reduzir atritos no atendimento. O foco principal é transformar comentários brutos em insights diretos e acionáveis para o negócio.

**Dados disponíveis:** Você receberá uma base de comentários contendo as seguintes informações: data do comentário, canal de atendimento utilizado, texto do feedback escrito pelo cliente, produto citado e nota de satisfação (escala de 1 a 5).

**Instruções de análise:**
1. Classifique os feedbacks recebidos por: tema central, sentimento (positivo, neutro ou negativo), urgência (alta, média ou baixa) e produto citado.
2. Identifique os principais padrões de comportamento: problemas mais frequentes, maiores motivos de elogios e oportunidades de inovação ou correção.
3. Aponte evidências reais nos dados fornecidos para embasar cada padrão, utilizando exemplos curtos dos comentários recebidos.
4. Sugira ações práticas e resolutivas para a equipe de experiência do cliente e para o time de canais digitais.

**Formato da resposta:**
Entregue o resultado estruturado da seguinte forma:
* Um **resumo executivo** de no máximo 5 linhas.
* Uma **tabela** contendo as colunas: Tema, Sentimento, Evidência e Ação Sugerida.
* Uma lista em tópicos com as **3 prioridades mais urgentes** para atuação imediata.

**Restrições e Cuidados:**
* Use estritamente os dados fornecidos.
* Não invente números, estatísticas, causas ou conclusões que não estejam na base de dados.
* Não exponha dados pessoais ou sensíveis sob nenhuma hipótese (anonimize qualquer informação identificável).
* Informe explicitamente as limitações caso os dados fornecidos não sejam suficientes para chegar a uma conclusão segura.
* Utilize uma linguagem executiva: simples, direta e focada em apoiar a tomada de decisão.
